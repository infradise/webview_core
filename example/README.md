# webview_core_example

Cross-platform testbed application demonstrating `webview_core` HTML rendering, dark/light background synchronization, JavaScript channels, and `IndexedStack` tab-switch visibility across Android, iOS, Linux, macOS, Windows, and Web / WebAssembly.

## Running Locally

From a clone of [`https://github.com/infradise/webview_core`](https://github.com/infradise/webview_core):

```bash
cd example
flutter run -d macos    # or -d windows / -d linux / -d chrome / -d ios / -d android
```
